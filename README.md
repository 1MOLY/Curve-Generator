# Curve Generator



A small and lightweight curve generator tool for engine torque curves and more. 

Made for BeamNG modders. <3



Metric system for the most part!

Output is ready to copy and paste!



##### Features:

\[  "name",                                      "input",                        "additions" ]

* Engine Torque Curve Generator                Metric Horsepower               Outputs torque
* Turbocharger Pressure Curve Generator        Turbo RPM !NOT ENGINE!
* Transmission Gear Ratio Generator            self-explanatory                Values easily usable in code and in-game



##### Usage:



1. Run the "generator.lua" script using Lua
2. That's it.
